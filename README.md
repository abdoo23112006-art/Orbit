# Orbit — Crew Health

تطبيق Flutter وDart لمتابعة صحة طاقم رحلة فضائية، مبني على تحدي NASA Space Apps 2026:
[Create Health Monitoring Software for Astronauts on Space Missions](https://www.spaceappschallenge.org/2026/challenges/health-monitoring-software/?tab=resources).

واجهة عربية افتراضيًا مع تبديل إلى الإنجليزية، واتجاه RTL، وتصميم يناسب الهاتف والشاشات الكبيرة.

## التشغيل

الإصدار الذي تم التحقق به: Flutter 3.47.7 / Dart 3.13.5.

```sh
flutter pub get
flutter run -d chrome
```

لجهاز Android متصل أو محاكي، شغّل `flutter run`. يتطلب Android SDK. لتشغيل iPhone تحتاج macOS وXcode وإعداد التوقيع. تم توليد مشاريع Android وiOS، لكن لم يتم بناء أو اختبار حزم الهاتف على هذا الجهاز لعدم توفر أدواتها. لا يوجد APK مرفق.

```sh
flutter analyze
flutter test
flutter build web --release --no-web-resources-cdn
flutter build apk --release
```

الأمر الأخير يحتاج Android SDK. لتشغيل نسخة الويب المبنية:

```sh
python3 -m http.server 8062 --directory build/web
```

ثم افتح `http://localhost:8062`.

## ما يعمل

- تسجيل نبض القلب، ضغط الدم بقيمتيه، الحرارة، السكر، النوم، والحالة النفسية، مع توقيت وملاحظات.
- حقول اختيارية، مع التحقق من المدخلات ومنع تسجيل وقت في المستقبل.
- عرض القيم الناقصة كغير مسجلة، دون عرض قياس قديم على أنه حديث.
- رسم المؤشرات خلال 7 أو 30 أو 90 يومًا.
- نطاقات متابعة توضيحية قابلة للتعديل، وتنبيهات عند الخروج عنها، وتذكير واضح عند قدم آخر قراءة.
- سجل قابل للفتح ونسخ تصدير JSON منه؛ التصدير يعرض البيانات ثم ينسخها عند اختيار المستخدم، ولا يرسلها.
- بيانات عرض محاكاة منفصلة عن السجل اليدوي. إضافة قراءة تنقل التطبيق إلى سجلك؛ زر البيانات التجريبية يعيد أمثلة العرض فقط.
- قائمة روتين يومي تُعاد حسب التاريخ المحلي. التسجيل الصحي يتحقق تلقائيًا عند وجود قراءة في اليوم.
- حفظ محلي للقراءات والإعدادات عبر shared_preferences. لا يوجد حساب أو خادم أو اتصال بحساسات.
- دليل رحلة بالمصادر الخمسة الرسمية، مع بيان دور كل مصدر في التصميم.

## حدود النموذج

هذا نموذج عرض للمسابقة، وليس جهازًا طبيًا أو نظام سجلات معتمدًا. النطاقات الرقمية افتراضية لشرح السلوك، وليست حدودًا معتمدة من ناسا أو تشخيصًا. مصادر التحدي تقدم سياقًا علميًا عامًا، ولا تحتوي على النطاقات الرقمية المستخدمة هنا. لا توجد توصيات أدوية أو جرعات أو استنتاج جرعات إشعاع من المؤشرات الحيوية.

الحفظ المحلي غير مشفر، ويمكن أن يضيع إذا حُذفت بيانات التطبيق أو المتصفح. shared_preferences غير مناسب للبيانات الحرجة. استخدم بيانات اختبار غير حساسة واحتفظ بنسخ مصدرة إذا احتجت إليها. نسخة الويب تحتاج تحميل ملفات التطبيق أولًا؛ لم يُنفذ ضمان تشغيل الويب بعد إغلاقه دون اتصال. الروابط الخارجية تحتاج الإنترنت.

## بنية المشروع

- `lib/health.dart`: نماذج القراءات والحفظ المحلي والنطاقات والموارد.
- `lib/main.dart`: اللغة والهوية البصرية.
- `lib/screens/home.dart`: لوحة المتابعة والرسوم والسجل ودليل المصادر.
- `lib/screens/check_in.dart`: نموذج القياس والتحقق من الإدخال.
- `lib/screens/preferences.dart`: إعداد النطاقات.
- `lib/screens/widgets.dart`: البطاقات والرسم البياني.
- `test/`: ستة اختبارات للبيانات وثلاثة اختبارات للواجهة، مع صور مرجعية.

تم التحقق من الحفظ وإعادة التحميل، وفصل بيانات العرض، وحالات تعذر الحفظ وتلف البيانات، وتغير التاريخ، والمدخلات غير الصالحة، والتنقل بالعربية، وتبديل اللغة، وأحجام 320×720 و390×844 و1440×1100. صور الواجهة ناتجة عن عرض Flutter في اختبارات الواجهة. تعذرت معاينة المتصفح آليًا لعدم توفر صلاحيات التحكم؛ بناء الويب نجح.

راجع `SOURCES.md` للمراجع، و`THIRD_PARTY.md` للتبعيات والتراخيص.

## إضافة المرجع المتحرك

أضيف مرجع شخصي متحرك لنبض الراحة، مع سياق القياس ومرحلة المهمة وخط إضافي على الرسم. راجع `DYNAMIC_BASELINE.md` لشرح الملفات والمعادلة والقيود. عدد اختبارات المشروع بعد الإضافة 21، وبيانات العرض أصبحت 14 يومًا. القياسات القديمة تظل محفوظة؛ يلزم سياق مُسجل صراحة للمشاركة في الحساب الجديد.

## صفحة الدخول للعرض

يبدأ التطبيق الآن بصفحة دخول تجريبية. الحساب `crew@orbit.demo` وكلمة السر `OrbitDemo2026!`. التغيير من `lib/demo_access.dart`. راجع `LOGIN_DEMO.md` للسلوك والملفات. هي واجهة عرض وليست مصادقة إنتاجية أو حماية للبيانات المحلية. عدد الاختبارات بعد الإضافة 26.

## مساعد COSMO

أضيف مساعد تعليمي عبر وسيط محلي يحتفظ بمفتاح API على الخادم. التشغيل في نافذتين من مجلد المشروع: `bash server/start.sh` ثم `bash run_cosmo.sh`. راجع `COSMO_SETUP.md` قبل التشغيل. الربط مبني على مثال API الذي زوّدنا به الفريق ولم يجرّب بمفتاح فعلي. عدد الاختبارات الآن 32 لـFlutter و9 للخادم، والطلبات الخارجية في الاختبارات محاكاة فقط. حساب الدخول التجريبي لا يحمي خدمة API عامة.
